# Sambisari guide images

The static image directory contains two documentary photographs and four guide graphics. The photographs were checked against Wikimedia Commons metadata on 19 October 2026:

- `01-sambisari-main-temple-crisco1492.jpg`: Crisco 1492, CC BY-SA 3.0. Source: https://commons.wikimedia.org/wiki/File:Candi_Sambisari_main_temple_2013-11-28_01.jpg
- `02-sambisari-complex-teshteh.jpg`: TeshTesh, CC BY-SA 3.0. Source: https://commons.wikimedia.org/wiki/File:Candi_Sambisari,_Hindu_Temple_of_Java_Indonesia_2013_b.jpg
- Licence: https://creativecommons.org/licenses/by-sa/3.0/

Local JPEG copies are resized/recompressed for delivery; no scene elements are altered. These are historical photographs, not guarantees of present access or site operations.

`03-sambisari-arch-logo.png`, `05-sambisari-strata-archive.webp`, `06-sambisari-stone-study.webp` and `07-sambisari-field-pattern.webp` are project-made guide graphics. They are decorative and do not reconstruct or replace the archaeological site. Original artwork copies remain in the source `assets/` directory; only optimized delivery files are served.
